# PoC presentation — holding notes

Do not build the slides yet. These notes preserve what the later PoC presentation must prove.

The room already heard the broad pitch. Do not spend five minutes repeating turnout, Pocket, or State Makers. Lead with the feedback and the changed product.

## One-line frame

“You told us the reveal must buy reading time, the design must carry the product, bootstrap is the hard part, and political content is a production problem. This PoC is our answer.”

## Proposed short structure

### 1. Feedback heard

Put four comments on one slide:

- FIFA walkout buys reading time
- Feel is crucial
- Bootstrap is the hard part
- Content volume can break the product

Then: “We rebuilt around those four risks.”

### 2. Demo first — the line before the name

Open a real pack. Do not explain the state machine before playing it.

1. Tear
2. Quote/fact appears alone
3. Source cue
4. Faction + type
5. Silhouette
6. Image + name
7. Full context and inspectable source

Say: “FIFA delays the player because anticipation is valuable. We spend that same anticipation on reading.”

Show reduced motion only if asked: movement disappears; information order remains.

### 3. Why the design is not decoration

- Signature = quote through the ballot slit
- One primary action
- Crisp staged motion, not ambient noise
- Paper / ink / foil, 8px party pip
- Rarity changes ceremony, not truth
- Source and advocacy disclosure stay visible

Measure: can a user repeat the hook before identity; do opened packs reach all six backs?

### 4. Agenda and content progression

State the supported sponsor/faction/agenda explicitly once configured.

“The rules do not change. The editorial program deepens.”

Show:

`orientation → issue contrast → decision readiness`

Use three PoC patterns:

- Quote → context → consistency test
- Same-issue paired receipts
- Commons → uncommon → rare argument

Important language: all quotations are exact and sourced; selection is editorial; the corpus is not claimed to be exhaustive balance.

### 5. Audience impact

These are evaluation scenarios, not separate hidden feeds.

**Quiet supporter:** private binder + optional anonymous participation + real aggregate activity. Test whether credible activity reduces isolation without outing them.

**Undecided:** broad orientation, then inspectable issue contrasts. Test source opens, issue-set completion, return, and clarity.

**Opposing supporter:** same rules, every set accessible, strongest argument represented before response, visible corrections. Test retention after critical cards and whether disagreement creates source inspection.

Do not claim vote conversion from a PoC. Claim that these are the mechanisms and measurements.

### 6. Bootstrap is a funnel, not “we’ll go viral”

Show the generated share artifact and exact-card deep link.

Seed:

- 10 creators
- 3 native formats
- 1 coordinated opening window
- creator/referral links

Funnel:

`pack → six backs → source → binder → share → referral → new guest`

PoC thresholds:

- 10 creators complete a pack
- 70% of opened packs reach all backs
- 30% create one share
- 20% of referral visitors begin a guest session
- 15% of completed backs inspect a source

If numbers fail, fix the broken conversion. Never solve bootstrap with fake activity.

### 7. Content scale answer

Show the pipeline:

`draft → fact-checked → approved`

Agent owns schema, checks, rendering, duplicate detection, word counts. Human editor owns quote accuracy, context, selection, rights, and approval.

The first 28 cards are the quality benchmark. Expansion is blocked by missing provenance, not by missing animation.

### 8. Close with the next test

“The next proof is not another strategy slide. It is whether ten seeded creators can make people open, read, inspect, and share this pack.”

Ask for:

- Named sponsor / supported agenda configuration
- Direct primary/reporting URLs for the showcase quote chains
- Seed creator list
- Five observed mobile playtests

## Demo safeguards

- Reset or use a fresh guest before presenting.
- Confirm the server is running and the pack is available.
- Preselect one quote card only as a labeled demo fixture if RNG would make the walkout impossible to demonstrate.
- Never describe fixture activity as live activity.
- Keep a screenshot/video fallback of the walkout.
- Open one source in the room.

## Numbers that belong in this PoC presentation

Use only:

- Six cards
- One pack / 24h
- 1.5s was the old simple hold; the new walkout uses short minimum beats plus tap control
- 28 PoC cards
- Bootstrap learning thresholds above

Prior turnout and market evidence can sit in appendix or answer questions. The audience already heard the introduction.
