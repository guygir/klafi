# Kalpi — Card bible

Anatomy, voice, neutrality, and rarity language. All PoC text lives in [poc-cards.md](poc-cards.md). Sources in [sources.md](sources.md).

---

## Voice

- **Hebrew on cards** in a shipped product. PoC backs are written in **English** so they can be pasted into the English deck; each card also has a Hebrew title.
- Reading age: a tired 19-year-old on the bus.
- Short, concrete, sourced. No lore. No campaign voice in our voice.
- Quotes are always labeled **Quote** and attributed with date + source.
- Never write a slogan as if it were a fact.

Back formula: **who / role / one fact that helps you vote.**

## Card anatomy

### Front

| Field | Required | Notes |
|---|---|---|
| Set badge | Yes | Party color pip **only here**. Shared chrome everywhere else. |
| Type chip | Yes | Member / Symbol / Platform / Quote / Commons |
| Title | Yes | Name, plank, or institution |
| Subtitle | Yes | List slot, office, or one-line identifier |
| Art | Yes | Illustrated or silhouetted. No scraped press photos in jam. |
| Rarity mark | Yes | C / U / R / H |
| Letter / mark | Symbol cards | Ballot letters as typography, not a stolen logo file |
| Date stamp | Holos only | `DD.MM.YYYY · #1 of 1 today` |

### Back

| Field | Required | Notes |
|---|---|---|
| Title (repeat) | Yes | Same as front |
| Body | Yes | 40–60 words. Equal length across a type. |
| Why it matters | Yes | One clause: what a voter can do with this fact |
| Source | Yes | Short citation, not a URL wall |
| Set + number | Yes | e.g. `LIK-M-01` |

Hard cap: **60 words** of body. If it needs more, it is two cards or it is a quiz.

## Objectivity (subgoal)

The game does not pick a side. Players may pledge a list as a **camp**; that is their energy, not ours. Cards, quizzes, rarity, and art weight stay even.

Quiz stems are identity and role, never “who should you vote for.”

---

## Neutrality checklist (every card, every party)

- [ ] Same slot types and counts as every other party set
- [ ] Body word count within ±8 words of the sibling cards of that type
- [ ] Same tone: no sarcasm, no “hero / villain” adjectives
- [ ] Party color only in the 8px badge, never as a full-bleed wash
- [ ] Art treatment equal (all illustrated, or all silhouette — never photo vs drawing)
- [ ] Source cited
- [ ] No joke that only one camp would laugh at
- [ ] List slots marked **as reported ahead of the 9 Sept 2026 CEC deadline** when not yet official

If a card fails any box, it does not ship.

## Imagery rules

- Illustrated or silhouetted civic portrait. No photorealistic likeness in the jam.
- Official party logos: do not scrape. Use **ballot letters as type**.
- Shared frame, shared type, shared foil language. See [visual-system.md](../design/visual-system.md).
