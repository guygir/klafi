# How to review

Read these pages **in order**. Pitch C and dense Pitch D preserve the prior product. The final four pages are the **current feedback-focused PoC decision** and supersede the old neutrality rule.

Use **← →** or the buttons. Mark a page reviewed when you are done with it. Progress is saved in this browser.

What you are looking for:

- Something we talked about that is **missing**
- Something that is **wrong** or no longer true
- Something that should be **on the pitch** but is only in a doc
- Something that should **stay off** the pitch

The upgraded HTML PoC ships in [`../../app/`](../../app/): server-owned daily pull → hook/source/faction/silhouette/identity walkout → contextual back → binder → sourced share/deep link. Run it with `cd app && npm start`, then open `http://127.0.0.1:4173`.
